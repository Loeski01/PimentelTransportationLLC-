Guarda un acceso a esta página en tu teléfono. / Save this page to your phone’s Home Screen.

iPhone / iPad
  1. Abre esta página en Safari. / Open this page in Safari.
  2. Toca Compartir (cuadrado con flecha hacia arriba). Si no lo ves, toca primero los tres puntos de Safari. / Tap Share; it may be inside Safari’s three-dot menu.
  3. Elige Agregar a inicio o Añadir a pantalla de inicio. / Choose Add to Home Screen.
  4. Deja el nombre “Pimentel Transportation” y toca Agregar. / Keep the name and tap Add.

Si falta esa opción, baja hasta “Editar acciones”. / If the option is missing, scroll to “Edit Actions”.

Android / Google Pixel
  1. Abre esta página en Chrome. / Open this page in Chrome.
  2. Toca el menú de tres puntos. / Tap the three-dot menu.
  3. Elige Instalar y crear acceso directo → Crear acceso directo. En otras versiones puede decir Agregar a la pantalla principal o Instalar aplicación. / Choose Install and create shortcut → Create shortcut. Other versions may say Add to Home screen or Install app.
  4. Confirma Agregar o Instalar. / Confirm Add or Install.

Si abriste el enlace dentro de WhatsApp u otra app, ábrelo primero en Safari o Chrome. Cada persona debe confirmar para guardar el icono. / If using an in-app browser, open in Safari or Chrome first. Each person must confirm.
